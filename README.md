# 👾 Hey, I'm an Indie Game Developer!

🎮 I'm an aspiring indie game developer from Kazakhstan, working mainly with **Godot Engine**.

👁️ I'm passionate about PSX-style horror games, retro aesthetics, low-poly graphics, and atmospheric storytelling. I enjoy creating unique gameplay mechanics, designing immersive environments, and experimenting with unusual ideas.

🛠️ **What I Do**
- Develop games and prototypes in Godot.
- Create gameplay mechanics and interactive systems.
- Experiment with level design, lighting, and atmosphere.
- Work on horror concepts and experimental game ideas.

🚀 **Experience & Goals**

I've worked on multiple Godot projects, including a paid development project and my own game prototype. I'm constantly learning, improving my skills, and turning new ideas into playable experiences.

🤝 **Collaboration**

I'm open to collaborating with other developers, artists, composers, and writers to create interesting indie games and bring ambitious ideas to life.

🎃 My main goal is to create memorable games with unique atmospheres, creative mechanics, and stories that stay with players.

📍 Kazakhstan

*Building strange worlds, one project at a time.* 👾
